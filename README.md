# ONG Esperança

Projeto desenvolvido para a disciplina de Desenvolvimento Front-end.

## Sobre o projeto

A aplicação da ONG Esperança foi criada com o objetivo de apresentar os projetos da organização e permitir o cadastro de pessoas interessadas em ajudar.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- localStorage
- SweetAlert2
- Git e GitHub

## Estrutura do projeto

- `index.html` - página inicial
- `projetos.html` - página com os projetos da ONG
- `cadastro.html` - página de cadastro
- `css/` - arquivos de estilo
- `js/` - arquivos JavaScript
- `imagens/` - imagens utilizadas no site

## Funcionalidades

- Navegação entre páginas
- Validação de formulário
- Armazenamento de dados com localStorage
- Manipulação do DOM
- Uso de eventos em JavaScript
- Recursos de acessibilidade

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão. Os commits seguem uma estrutura simples baseada em Conventional Commits, utilizando termos como `feat` para novas funcionalidades e `fix` para correções.
